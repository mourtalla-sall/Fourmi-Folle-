# Fourmi-Folle 🐜

Simulation de la fourmi de Langton en HTML, CSS et TypeScript.

## Règles

- Case blanche : la fourmi tourne à droite, la case devient noire, la fourmi avance.
- Case noire : la fourmi tourne à gauche, la case devient blanche, la fourmi avance.

## Lancer le jeu

1. Ouvre un terminal dans le dossier du projet.
2. Compile le code :
   ```bash
   npx -p typescript tsc
   ```
3. Ouvre `index.html` dans ton navigateur.

Après chaque modification de `main.ts`, recompile avec la même commande.

## Fichiers

- `index.html` : la page
- `styles.css` : le style
- `main.ts` : le code du jeu
- `main.js` : créé par la compilation
